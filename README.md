# 🎵 SpotifyToTelegram Bot

**SpotifyToTelegram** — это мощный Telegram-бот с полноценным визуальным интерфейсом (Mini App) для скачивания музыки из Spotify в максимальном качестве. Бот не требует платного Premium-аккаунта Spotify для разработчиков, поддерживает выборочное скачивание, сохраняет ID3-теги, красивые обложки и имеет встроенную систему синхронизации.

---

## 🌟 Ключевые возможности

1. **Скачивание любой сущности:** Треки, Альбомы, Плейлисты, Персональные миксы (Daily Mix и др.).
2. **Telegram Mini App:** Полноценный визуальный плеер внутри Telegram. Вставляете ссылку — получаете красивый список треков, можете **послушать 30-секундное превью** и выбрать галочками, что именно скачать.
3. **Продвинутая система скачивания (yt-dlp + FFmpeg):** 
   - Поиск по базе YouTube Music по точным совпадениям (Название + Исполнитель).
   - Точная проверка длительности (с погрешностью до 12 секунд), чтобы избежать скачивания клипов/ремиксов.
4. **ID3 Теги и Обложки:** К каждому скачанному MP3-файлу "вшивается" оригинальная обложка из Spotify, название, исполнитель и альбом. В Telegram музыка отображается идеально.
5. **Умное кэширование (SQLite):** Бот запоминает уникальные ID (file_id) загруженных в Telegram треков. При повторном скачивании трек мгновенно отправляется из кэша серверов Telegram без повторной загрузки.
6. **Управление загрузкой:** Во время загрузки больших плейлистов доступны кнопки **Пауза ⏸**, **Продолжить ▶️** и **Отмена 🛑**.
7. **Авто-синхронизация (`/sync`):** Бот может регулярно проверять плейлист и автоматически докачивать новые треки.
8. **Авто-туннелирование (Cloudflare):** Бот сам поднимает HTTPS-туннель при старте для работы Mini App, так как Telegram требует HTTPS.

---

## 🛠 Архитектура и стек технологий

- **Язык:** Python 3.10+
- **Фреймворк бота:** `aiogram` 3.x (полностью асинхронный)
- **Web-сервер (Mini App API):** `aiohttp` + SSE (Server-Sent Events) для прогресс-бара.
- **Frontend (Mini App):** HTML5, Vanilla JS, Tailwind CSS (через CDN), Telegram WebApp SDK.
- **База данных:** SQLite + `SQLAlchemy` (v2.0) + `aiosqlite`.
- **Фоновые задачи:** `APScheduler` (проверка обновлений плейлистов).
- **Парсинг Spotify:** Прямые запросы к Spotify Embed (не требует ключей Web API, обходит ограничение 403 Premium Required).
- **Загрузка и конвертация:** `yt-dlp` + `FFmpeg`.
- **Туннель:** `cloudflared` (бесплатные quick tunnels).

## 🚀 Установка и настройка (Windows)

### 1. Подготовка системы
1. Установите Python 3.10 или новее.
2. Установите **FFmpeg** (через WinGet):
   ```cmd
   winget install Gyan.FFmpeg
   ```
3. Установите **Cloudflared** (для туннеля Mini App):
   ```cmd
   winget install Cloudflare.cloudflared
   ```

### 2. Установка бота
Скачайте проект, откройте терминал в папке проекта и выполните:
```cmd
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте `_env.example` в `.env` (или создайте файл `.env`) и заполните данные:

```env
# Токен вашего бота (получить у @BotFather)
BOT_TOKEN=123456789:ABCDefgh_IJKL_mnop

# Ваш личный Telegram ID (узнать у @userinfobot)
# Гарантирует, что ваш куки SP_DC используете ТОЛЬКО вы!
OWNER_TELEGRAM_ID=867551644

# (Опционально) Cookie для ваших персональных миксов (Daily Mix и др.)
SPOTIFY_SP_DC=ваш_cookie_sp_dc
```

> 🔒 **Безопасность вашего аккаунта Spotify (`SP_DC`):**
> Бот защищён: ваш личный куки `SPOTIFY_SP_DC` используется **исключительно** при ваших собственных запросах (`OWNER_TELEGRAM_ID`). 
> Когда другие пользователи скачивают музыку или присылают ссылки, бот делает строго анонимные запросы и **не передаёт ваш куки третьим лицам**.

> ⚠️ **Лимит в 100 треков на плейлист:**
> - Из-за ограничений виджета Spotify Embed бот загружает **первые 100 добавленных в плейлист треков** (хронологически первых).
> - Если ваш плейлист содержит больше 100 песен (например, 150–200), в Spotify просто разделите его на два списка (по <100 треков) и скормите боту обе ссылки.

## ▶️ Запуск

Бот автоматически поднимет web-сервер, запустит cloudflare туннель и начнет принимать сообщения.

Просто запустите файл (если вы создавали глобальный алиас):
```cmd
spotifybot
```
Или напрямую:
```cmd
.\run.bat
```

В консоли вы увидите:
```
[INFO] - Запуск cloudflared туннеля...
[INFO] - Туннель поднят! URL: https://some-random-words.trycloudflare.com
[INFO] - Кнопка меню (слева от скрепки) успешно обновлена!
[INFO] - Бот успешно запущен!
```

## 📱 Как использовать

1. **Обычная загрузка:** Отправьте боту команду `/start`, а затем скиньте ссылку на любой трек или плейлист Spotify. Бот начнет скачивание.
2. **Mini App (Плеер):**
   - Нажмите кнопку **«🎵 Открыть плеер»** (в сообщении от `/start` или слева от скрепки).
   - Вставьте ссылку на плейлист.
   - Послушайте превью (клик по обложке).
   - Выберите треки и нажмите "Скачать". Следите за прогресс-баром!
3. **Управление загрузкой плейлиста:** Под сообщением статуса появятся кнопки "Пауза" и "Стоп". Вы можете приостановить загрузку из 100 треков и продолжить её позже.
4. **Синхронизация:** `/sync https://open.spotify.com/playlist/...` — бот будет каждые 15 минут проверять плейлист и присылать вам новинки.

## 📁 Структура проекта

```text
SpotifyToTelegram/
├── bot/                # Логика Telegram-бота (aiogram)
│   ├── handlers/       # Обработчики команд (/start, /download, /sync)
│   └── keyboards/      # Inline-кнопки (Пауза, Стоп)
├── db/                 # База данных (SQLAlchemy)
│   ├── database.py     # Подключение к SQLite
│   ├── models.py       # Таблицы: Chat, SyncPlaylist, SentTrack
│   └── repository.py   # CRUD операции
├── services/           # Бизнес-логика
│   ├── spotify.py      # Парсинг Spotify Embed (без ключей API)
│   ├── downloader.py   # yt-dlp интеграция
│   ├── tagger.py       # Мутаген (ID3 теги и обложки)
│   ├── job_manager.py  # Управление фоновыми загрузками (Пауза/Возобновление)
│   └── processor.py    # Связующее звено: скачать -> тегировать -> отправить
├── webapp/             # Telegram Mini App
│   ├── api.py          # aiohttp REST API сервер
│   └── static/         # Frontend: index.html (UI плеера)
├── worker/             # Фоновые процессы
│   └── scheduler.py    # APScheduler для /sync
├── config.py           # Настройки и загрузка переменных окружения
├── main.py             # Точка входа (запуск бота, web-сервера, cloudflared)
└── run.bat             # Скрипт запуска
```
