**SpotifyToTelegram** — продвинутый асинхронный Telegram-бот и веб-платформа для поиска, прослушивания и пакетного скачивания музыки из Spotify в высоком качестве (MP3 256–320 kbps). 

Проект включает **Telegram Mini App (веб-плеер)**, **отказоустойчивый мульти-источник скачивания (YouTube + SoundCloud fallback)**, **пакетную загрузку треклистов из `.txt` файлов с защитой от спама**, а также **веб-дашборд с детальной аналитикой и определением жанров через Last.fm API**.

## ✨ Ключевые возможности

### 🎧 Музыкальный движок
- **Мульти-источники скачивания:** Поиск в YouTube Music с автоматическим переключением на **SoundCloud** при блокировках дата-центров (`Sign in to confirm you're not a bot`).
- **Сверка хронометража (Duration Matching):** Строгая проверка длительности с точностью до секунды отсекает клипы, длинные вступления, живые концерты и фанатские ремиксы.
- **Вшивание ID3-тегов и обложек:** С помощью `mutagen` в каждый MP3 внедряется официальная HD-обложка, артисты, название альбома и год выпуска.
- **Мгновенный кэш Telegram:** Треки, которые уже скачивались любым пользователем, сохраняются в базе данных по `telegram_file_id` и отправляются моментально без повторной загрузки.

### 📥 Пакетная загрузка и обход ограничений
- **Поддержка любых ссылок Spotify:** Треки, альбомы, плейлисты, персональные миксы (*Made for You*, *Daily Mix*).
- **Импорт из текста и `.txt` файлов:** Отправка текстовых списков или `.txt` файлов со 100–200+ ссылками.
- **Ленивая загрузка (Lazy Metadata):** Информация о треках запрашивается поштучно непосредственно перед скачиванием, предотвращая бан по IP от Spotify.
- **Интеллектуальная защита от спама (Anti-Spam Cooldown):** При пакетных загрузках бот скачивает порцию из 30 песен и делает 2-минутную паузу для защиты инфраструктуры.
- **Параллельная обработка:** Пул воркеров (`asyncio.Queue`) скачивает до 3 треков одновременно с троттлингом Telegram API.

### 🔄 Авто-синхронизация
- Команда `/sync <playlist_url>` привязывает плейлист к чату или каналу.
- Встроенный `APScheduler` каждые 15 минут проверяет плейлист и автоматически досылает только появившиеся новинки.

## 📊 Админ-панель и аналитика

В проект встроена полноценная веб-панель управления с адаптивным дизайном в стиле Spotify Dark Theme.

- **URL:** `https://your-domain.com/admin/` (или `http://localhost:8080/admin/`)
- **Защита:** Авторизация по паролю с сохранением защищенных сессионных `HttpOnly` Cookies на 24 часа.

### Возможности дашборда:
1. **Сводные карточки:** Общее число пользователей, суммарные скачивания, процент успешности (% success rate) и активность за сегодня.
2. **Интерактивные графики (Chart.js):**
   - 📈 *Динамика за 30 дней:* линейный график скачиваний.
   - 🕒 *Активность по часам:* гистограмма пиковой нагрузки в течение суток.
   - 🍩 *Популярные жанры:* круговая диаграмма музыкальных предпочтений на основе Last.fm.
   - 🥧 *Источники аудио:* распределение между YouTube, SoundCloud и Telegram Cache.
3. **Аналитические таблицы:**
   - 🏆 Топ скачиваемых треков.
   - 🎤 Топ популярных исполнителей.
   - 👥 Список пользователей с языком интерфейса Telegram (`language_code`) и датой активности.
4. **Real-Time обновление:** Автоматическое обновление метрик каждые 60 секунд без перезагрузки страницы.

## 🌐 Telegram Mini App

Бот включает интерактивное веб-приложение прямо внутри интерфейса Telegram (кнопка меню «Плеер» слева от поля ввода):

- **Аудио-превью:** Прослушивание 30-секундных отрывков композиций перед скачиванием.
- **Выборочный экспорт:** Возможность отметить чекбоксами нужные песни из плейлиста или выбрать все сразу.
- **Real-Time прогресс:** Индикатор выполнения загрузки с передачей событий через **Server-Sent Events (SSE)**.
- **Нативная интеграция:** Адаптация под тёмную/светлую тему Telegram и поддержка Haptic Feedback.

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` в корневой папке проекта на основе примера:

```ini
# =================================================================
# ОБЯЗАТЕЛЬНЫЕ НАСТРОЙКИ
# =================================================================
# Токен бота, полученный у @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ

# Ваш личный числовой Telegram ID (узнать у @userinfobot)
OWNER_TELEGRAM_ID=867551644

# =================================================================
# ВЕБ-СЕРВЕР И АДМИН-ПАНЕЛЬ
# =================================================================
# Порт для веб-сервера Mini App и админки (по умолчанию 8080, Render задает свой)

# Постоянный URL приложения (например, на Render или собственный домен)
# Если пусто или localhost — бот локально поднимет бесплатный cloudflared туннель
WEBAPP_URL=https://spotifytotelegram.onrender.com

# Пароль для входа в веб-дашборд /admin/ (по умолчанию: admin)
ADMIN_PASSWORD=my_super_secret_password

# =================================================================
# ДОПОЛНИТЕЛЬНЫЕ ИНТЕГРАЦИИ (ОПЦИОНАЛЬНО)
# =================================================================
# Бесплатный API ключ Last.fm для автоматического определения жанров
# Получить за 1 минуту: https://www.last.fm/api/account/create

# Cookie sp_dc из браузера для доступа к личным подборкам Spotify (Made For You)
# ВАЖНО: Используется ТОЛЬКО владельцем бота (OWNER_TELEGRAM_ID)!
SPOTIFY_SP_DC=
```

## 🚀 Развертывание и запуск

### Вариант А: Облако (Render.com / Docker)

Проект полностью оптимизирован для бесплатного хостинга **Render.com**.

1. Сделайте **Fork** или загрузите этот репозиторий в свой **GitHub**.
2. В панели [Render Dashboard](https://dashboard.render.com/) нажмите **New ➔ Web Service**.
3. Подключите ваш GitHub-репозиторий.
4. Выберите среду: **Docker** (Render сам обнаружит `Dockerfile`).
5. Укажите тарифный план: **Free**.
6. Во вкладке **Environment Variables** добавьте:
   - `BOT_TOKEN`
   - `OWNER_TELEGRAM_ID`
   - `WEBAPP_URL` (значение вида `https://<ваше-имя-сервиса>.onrender.com`)
   - `ADMIN_PASSWORD`
   - `LASTFM_API_KEY` *(опционально)*
7. Нажмите **Deploy Web Service**.

> 💡 **Как держать бота активным 24/7 на бесплатном тарифе Render:**
> Бесплатный тариф Render засыпает через 15 минут неактивности по HTTP. Чтобы бот не спал:
> 1. Зарегистрируйтесь на бесплатном сервисе [cron-job.org](https://cron-job.org/).
> 2. Создайте задачу на пинг вашего адреса: `https://<ваше-имя-сервиса>.onrender.com/` с интервалом **каждые 14 минут**.

---

### Вариант Б: Локальный запуск (Windows / Linux / macOS)

#### 1. Системные зависимости
- **Python:** 3.10 или выше.
- **FFmpeg:** Должен быть установлен и добавлен в `PATH`.
  - *Windows (WinGet):* `winget install Gyan.FFmpeg`
  - *Ubuntu/Debian:* `sudo apt update && sudo apt install -y ffmpeg`
  - *macOS (Homebrew):* `brew install ffmpeg`
- **Cloudflared (опционально, для локального туннеля Mini App):**
  - *Windows:* `winget install Cloudflare.cloudflared`

#### 2. Установка и запуск
```bash
# Клонирование репозитория
git clone https://github.com/QazaKod/SpotifyToTelegram-.git
cd SpotifyToTelegram-

# Создание и активация виртуального окружения
python -m venv .venv

# Windows:
.\.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

При локальном запуске без указания `WEBAPP_URL` бот автоматически запустит бинарник `cloudflared`, создаст защищённый HTTPS-туннель и сам зарегистрирует кнопку Web App в Telegram!

## 💡 Как пользоваться ботом

| Действие | Как выполнить |
|---|---|
| **Одиночный трек** | Отправьте ссылку вида `https://open.spotify.com/track/...` |
| **Альбом / Плейлист** | Отправьте ссылку `https://open.spotify.com/playlist/...` — появится панель с кнопками паузы/отмены. |
| **Выборочное скачивание** | Нажмите кнопку меню **«Плеер»** слева от скрепки, вставьте ссылку и выберите треки вручную. |
| **Большие списки (100–500 треков)** | Отправьте боту `.txt` файл со ссылками или вставьте список ссылок прямо в сообщение. |
| **Синхронизация плейлиста** | `/sync https://open.spotify.com/playlist/...` — новые треки будут досылаться раз в 15 минут. |
| **Управление очередью** | Команды `/pause`, `/resume`, `/stop` или интерактивные inline-кнопки под сообщением. |

## 🛡 Безопасность и лимиты

1. **Защита персонального аккаунта Spotify (`SP_DC`):**  
   Куки авторизации используется **исключительно** тогда, когда запрос инициирован владельцем (`OWNER_TELEGRAM_ID`). Запросы всех остальных пользователей обрабатываются в строгом анонимном режиме.
2. **Лимит Spotify Embed (100 треков):**  
   Публичный виджет Spotify отдаёт до 100 треков плейлиста. Для обхода этого ограничения используйте пакетную отправку ссылок через `.txt` файл — бот загрузит неограниченное количество треков.
3. **Безопасность админ-панели:**  
   Доступ к аналитическим API и странице `/admin/dashboard` защищен криптостойким токеном в `HttpOnly` Cookie. Запросы без валидной сессии отклоняются с кодом `401 Unauthorized`.
